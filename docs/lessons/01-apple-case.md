# 从苹果案例辨别真实问题

对应源文档页码：5-6。本笔记为独立学习改编。

## 要理解的机制

把品牌、类目、规格、渠道和时间拆开。最新由目录字段决定，价格由报价源决定。水果、配件、旧促销和其他市场是不同的 hard negative。

## 可运行实验

```bash
uv run rag-lab ask "苹果最新手机多少钱"
uv run rag-lab ask "PHONE-A-256 S01 到店会员价多少钱"
```

## 验证与观察

先观察缺参数追问，再观察精确规格的整数分报价。尝试把 S01 改成 S99，确认服务拒绝。

## 进阶练习与边界

新增一个水果营销页包含 phone，比较 BM25、dense 和融合。不要预设混合一定胜出。

## 自测

1. 哪种失败不能通过更强的检索模型修复？
2. 本实验锁定了哪些条件，还缺少哪些真实业务证据？
3. 如果撤权、超时或来源冲突发生在这一阶段，应怎样输出？
