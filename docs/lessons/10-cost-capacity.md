# 延迟、容量与成本

对应源文档页码：23-24。本笔记为独立学习改编。

## 要理解的机制

两百万乘1536乘4仅是原始向量字节，不包含图、元数据、复制和迁移。组件 P95 相加不等于整体 P95。单位成功任务成本的分母是通过业务验收的请求，而不是所有尝试。Little 定律只估平均在途。

## 可运行实验

```bash
uv run rag-lab capacity
uv run rag-lab benchmark --requests 200 --workers 8 --output reports/benchmark.json
```

## 验证与观察

确认 12.288 GB 与 11.44 GiB 的区别，并查看实测本机 P50/P95/P99、错误数和吞吐。数字不是 GPU、数据库或生产 SLO。

## 进阶练习与边界

加入冷暖缓存、0.1%-100% 权限选择性、长查询、持续更新、网络故障和突发流量；记录完整请求 trace。
