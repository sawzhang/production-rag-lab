# 召回、融合、重排与失效诊断

对应源文档页码：10-12。本笔记为独立学习改编。

## 要理解的机制

RRF 用排名，不混合原始评分量纲。未截断并集覆盖与融合截断覆盖必须分别报告。重排只能排序已有候选；当前 token overlap 是教学基线，不是 CrossEncoder。每一路 top K、总候选和最终证据都有独立预算。

## 可运行实验

```bash
uv run rag-lab sweep --split dev --output reports/sweep.json
```

## 验证与观察

比较同一查询的单路、并集、截断、重排后召回。Q46 演练重排超时回退，且回退仍满足 ACL。

## 进阶练习与边界

固定同一个候选集合比较两个真实 reranker，再单独扩大预算。调参仅使用 dev，不用 holdout 挑最优参数。

3. 如果撤权、超时或来源冲突发生在这一阶段，应怎样输出？
