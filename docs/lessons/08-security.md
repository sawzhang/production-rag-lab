# 权限、安全与不可信内容

对应源文档页码：19-20。本笔记为独立学习改编。

## 要理解的机制

ACL 必须早于模型看到候选，返回时再次核对以处理撤权竞态。父块不能继承子块授权。缓存包含身份、范围、策略 epoch、语料 generation、时间和模型版本。文档和工具数据不能升级为指令。

## 可运行实验

```bash
uv run pytest -k "acl or revocation or Q37 or Q38 or Q39 or Q40 or Q41 or Q42"
```

## 验证与观察

Spy 模型断言收到的候选没有另一租户和私密父段；在重排中撤权后，最终证据应为空。

## 进阶练习与边界

生产还需会话再授权、日志/导出权限、DLP、出网白名单、字段级授权及隔离统计量。当前没有共享答案缓存和任何外部生成 API。
