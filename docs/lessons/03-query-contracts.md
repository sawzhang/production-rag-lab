# 查询理解与精确约束

对应源文档页码：8-10。本笔记为独立学习改编。

## 要理解的机制

保留原问题、完整 ID 与前导零，金额使用整数分。lt 与 le、超过与至少必须分开。身份字段来自可信上下文。有效时间不等于上传时间，相对时间必须绑定时区。当前规则解析器只覆盖明确示例，不是通用 NLU。

## 可运行实验

```bash
uv run pytest tests/test_document_regressions.py -k "Q13 or Q14 or Q15 or Q18 or Q23"
```

## 验证与观察

500000 分必须排除在低于 5000 元之外，却包含在不高于 5000 元中。检查 UTC 与上海时间表示同一瞬间。

## 进阶练习与边界

为每个字段加入用户指定/企业默认来源标签，加入复杂否定和单位换算；改写必须保护原始字符串。
