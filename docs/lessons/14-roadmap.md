# 90 天路线与发布闸门

对应源文档页码：30-31,37。本笔记为独立学习改编。

## 要理解的机制

1-15 天限定场景与 owner；16-30 天打通只读链路；31-60 天补失败样本、消融和恢复演练；61-90 天影子/灰度/稳定分桶实验。百人团队并不意味着百人专项团队。

## 可运行实验

```bash
make verify
```

## 验证与观察

本仓库的发布闸门是学习实现验证；真实生产还需批准的 SLO、合法来源、业务验收和人工审核的测试集。
