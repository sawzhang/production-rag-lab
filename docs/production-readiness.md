# 从学习实验到生产验收

## 本地已验证（见 reports/validation.md）

- 权限前置、父块再授权、取原文和输出复核、重排期间撤权。
- 整数分、编号前导零、价格和数量边界、当前与未来有效版本。
- 权威服务不可用不猜价、来源冲突提示、未识别错误码无答案、只读工具白名单。
- 幂等与乱序版本、删除及撤权账本跨快照/新进程恢复。
- BM25/LSA/RRF/weighted/overlap 五种同语料实验、合法 gold 指标和并发本机请求。

## 尚需真实系统验证

|能力|当前边界|生产验收证据|
|---|---|---|
|身份与对象权限|构造的 Identity fixture|SSO、网关服务端注入、组变更、字段脱敏、源引用再鉴权|
|数据持久化|内存/JSON，无事务，无多进程协调|事务 ledger/outbox、CDC、源对账、持久清理回执|
|撤回传播|无实际倒排/向量数据库或答案缓存|向量、全文、父块、摘要、会话、缓存、备份逐路径演练|
|embedding/重排|默认 LSA/overlap；真实适配器可选|锁定模型、真实中文测试、截断/吞吐/许可证审核|
|ANN|默认 exact|同过滤条件 exact 对照、窄权限和量化损失|
|生成|默认来源片段展示|引用支持、关键事实、拒答/误拒、人工校准评审|
|超时|重排等待超时；线程不能强制杀死|HTTP/socket deadline、取消、扇出、重试与总请求预算|
|历史事实|订单固定快照，无历史报价服务|真实业务事件/快照契约；不能假造 as_of 能力|
|CMDB|合成登记图，无实时观测|边来源、观测时间、方向、缺口与线上消费者验证|
|解析|保留段落，超长块拒绝|表头/跨页/OCR/页坐标、数字单位人工复核|
|可观测性|本地 trace，未建监控|脱敏、保留、访问控制、故障告警与授权回放|
|发布|公开代码与 CI|影子、canary、稳定分桶 A/B、批准的 SLO 和事故回退|

## 发布条件

至少 300-500 条经过领域审核的分层真实问题；关键金额、ID、状态、安全切片满足批准的门槛，并设可回答题完成率和误拒上限。严重越权或关键金额错误应阻断对应范围。用业务任务成功率、P95/P99、更新水位和每千次有效回答成本共同决策。

恢复和索引/模型回滚不得回滚删除及权限账本。未覆盖能力继续保留“未验证”状态。任何退款、改价、重启、消息重放属于独立授权的写入流程，不由诊断证据自动触发。
